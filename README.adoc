== Descripció
Nothingan Pri S.A és una aplicació web de lloguer de vehicles. Permet als clients registrar-se, reservar un vehicle per hores o dies i gestionar les seves reserves. Els agents i l'administrador validen els clients, gestionen la flota i controlen el lliurament i la devolució dels vehicles.

== Funcionalitats principals
* Registre i inici de sessió d'usuaris amb contrasenya xifrada.
* Tres rols: client, agent i administrador.
* Validació de clients per part d'un agent (pendent, validat o rebutjat), amb control de la caducitat del DNI i del carnet de conduir.
* Gestió de vehicles: marca, model, categoria, combustible, transmissió, preu per hora i estat (disponible, llogat o inactiu).
* Reserves de vehicles amb codi únic, import total i fiança.
* Anul·lació de reserves amb percentatge de devolució de l'import.
* Lliurament i devolució del vehicle, amb registre d'incidències, desperfectes i descompte per retard.
* Clients premium amb descompte.

== Tecnologies i eines utilitzades
* *Llenguatge:* Java
* *Framework:* Spring Boot
* *Vistes:* Thymeleaf, HTML i CSS
* *Persistència:* Hibernate (JPA)
* *Base de dades:* MySQL 8
* *Control de versions:* Git, GitHub i GitLab
* *Gestió del projecte:* Jira
* *Altres eines:* MySQL Workbench
